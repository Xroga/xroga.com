# Universal product synthesis

Status: **Implemented**, with external provider and chain actions explicitly gated.

`runUniversalSynthesisFoundation` executes understanding, capability graph, architecture, capability compilation, operations-manifest, verification-plan and evidence stages through the Command 1 scheduler and one canonical execution state. A stage is completed only after its handler executes and returns validation evidence. The resulting product definition, graph, executable plan, architecture, dependency inventory, operations manifest and verification plan share one content-addressed result.

Unknown legitimate requests are derived from actors, workflows, data, permissions and runtime needs instead of a fixed product category. External credentials, deployments, purchases and transactions remain actions for the owner to authorize.
