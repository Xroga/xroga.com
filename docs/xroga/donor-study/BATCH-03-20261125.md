## Decisions taken on the open items (owner authority, no question asked)

- **Reference-image search, built**: `find_image` takes the ref of an element showing a picture (icon, logo, swatch) and returns every place that picture appears on the page, as fractions for `canvas at` (grey mean-absolute-difference, coarse search on a reduced picture, refined at full size; flat templates refused). `src/agent/template-match.ts`, `template-match.test.ts` (3), Chromium `S4-find-image-and-language` (both copies found at their true positions). This replaces Ui.Vision's visualSearch, visualVerify and the search-area limits.
- **Recognition languages, built**: `ocr` takes `language`: english, arabic, urdu, hindi, spanish, french, german, portuguese, russian, chinese (tessdata_fast models, Apache-2.0, vendored in `public/ocr/lang`, one worker per language, released after a minute). Spanish verified in Chromium. `public/ocr` is now 19 MB.
- **Backend `http_get` change**: stays code-complete and undeployed. A production deploy goes through the existing release pathway after its gates; nothing in the extension needs it to be live.
- **Icon detector model (OmniParser)**: not built. Set-of-marks (edges), painted text, `ocr` and `find_image` now cover what a detector would find without a model download, onnxruntime and GPU needs; revisit only if a real task fails for lack of it.
- **`setProxy`**: refused on purpose. It would route all of a person's traffic through an address a page or a model could name; that is a security hole, not a missing feature.
- **Operating-system control (XClick, XType, desktop screenshots)**: impossible for a browser extension; nothing to build.

## Proven live

- `tracedraw.github.io/tracedraw/`, a Rust/egui/WebGL editor, in Chromium on 2026-11-25 (scripted tool calls, no model): while its 41 MB module loads, the overlay `<rect>` is correctly refused as a non-canvas target; after load the screenshot numbers 90 marks, the accessibility tree names a canvas and a textbox, and a canvas click dispatches ("effect: unattributable", which is the honest report for a canvas). Text painted by WebGL is not recorded by the 2D hook (documented limit); marks are the way in.
