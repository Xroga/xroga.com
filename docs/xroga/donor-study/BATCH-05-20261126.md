# Batch 5 (ledger rows 41 to 50): study and result, 2026-11-26

Status: **built, tested on real files and sites, pushed on `claude/ops-integrated-20261112`** (see "Test evidence").

Each repository was cloned at the pinned commit (`C:\xr-donors`) and read for what it contains: README, source layout, the code paths that matter, tests, docs and skills. Ideas were taken and the code was written fresh; the one library that is shipped (mediabunny, MPL-2.0) is vendored unmodified with its licence text. The batch is about video and audio: five video editors, an editing-spec tool, a media library and a wasm port of ffmpeg, plus an agent evaluation framework.

## Not done, said plainly

- `compose_video` has no GL transitions, no free keyframe animation of any property (fades, zoom, slide-in and speed are the built-in motions), no colour wheels or curves (the effects are brightness, contrast, saturation, blur, grayscale, sepia and hue) and no audio effects (EQ, noise reduction, ducking); the sound of a video layer follows `speed` with its pitch.
- Only https addresses, 3 minutes, 60 clips, 1920×1080. A file larger than 150 MB is refused.
- A picture or film that needs a sign-in is not reachable (the fetch sends no cookies).
- `media` reads at most 10 minutes per call (use `from` for the rest). Scene detection compares frames every quarter second or more, so a flash of fewer frames can be missed. Loudness is the integrated BS.1770 value of the part read, not of the whole file. Decoding depends on the browser's codecs.
- The beat tracker refuses a steady tone or hiss and finds no beat in speech; for music with a changing tempo, read in parts and compare.
- `webmcp` needs the page to register tools; a page that checks for `navigator.modelContext` may behave differently for a tab that is shared with the agent, because the hook supplies it where the browser has none. A tab opened before it was shared has no list until it is reloaded (the tool offers `reload`).
- ffmpeg.wasm is not vendored (licence, above), so a conversion that needs a codec the browser cannot encode is not possible.
- openreel's noise reduction, EQ, colour wheels and keyframes, and motion-canvas's code-defined scenes, were read and not built.
