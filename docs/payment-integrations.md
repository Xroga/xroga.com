# Payment integrations

Status: **Implemented in sandbox-capable adapters**; live activation is **external setup required**.

Stripe, PayPal and Lemon Squeezy adapters cover credential probes, checkout/order creation, provider-verified webhooks, durable idempotency, refunds/cancellations and entitlement state. A checkout redirect is not payment success. Live status requires owner credentials and real provider evidence; no live transaction was performed by Command 2C.
