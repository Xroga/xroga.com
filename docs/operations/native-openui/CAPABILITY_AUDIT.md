# Native Workspace capability audit

[Machine-readable coverage](coverage.json) records the four pinned source revisions, 55 registered components, 30 registered functions, every Open Intelligent UI base component, 59 Open Intelligent UI functions and 69 CopilotKit standard catalog entries. The [generated registry](../../../backend/src/ai/nativeOpenUiCatalog.json) is the exact model-facing schema for eligible rich answers. Short prose uses the compact instruction path. Catalog dispositions record implementation decisions and distinguish local verification from live acceptance.

| Upstream | Running integration | Evidence and limits |
| --- | --- | --- |
| OpenUI, `5afae00a` reference source, `@openuidev/lang-core` and `@openuidev/react-lang` pinned to 1.1.0 | Generated instructions, bounded Lang parsing, one React registry, validated rendering, local bindings and complete-prefix support. | Spec generation and backend validator tests. Prefix rendering is fixture-tested. The live Workspace route publishes a settled result rather than exposing raw provider token deltas. |
| Open Intelligent UI, `9df2e64b` | Layout, text, cards, badges, popovers, carousel, SVG, charts, sortable tables, code, math, inputs, date picker, timer, and local calculation functions. The expanded registry adds bounded list helpers, histogram bins and hexadecimal color mixing. | The vendored source retains MIT provenance. Chrome exercises chart data, sorting, keyboard slider, reset, date changes, timer controls and a local Lucide sprite. Unit tests cover bounds and deterministic calculations. |
| CopilotKit, `c7815d9a` | Tabs with keyboard selection, searchable ChoicePicker with Apply/Cancel, and local review state. The adapters are registered in OpenUI. | Chrome tests exercise tab semantics and draft/apply/cancel. The catalog’s existing-equivalent entries are compatibility findings, not additional CopilotKit runtime integrations. |

Map tiles, route geometry and model-selected media remain provider-gated. No approved resolver binds those assets to this renderer’s trusted resource IDs. Travel answers can still use verified links, tables and explicit caveats. Existing file previews and downloads retain their own access boundary. Upstream HtmlView, unsolicited media playback, arbitrary URL loading, second runtimes and remote actions remain excluded. Clock- and random-dependent functions are excluded for deterministic replay. The coverage file lists the decision for each audited function; some boundedness, output-key and interaction cases remain pending.

The icon catalog contains 1,986 Lucide names from the installed ISC-licensed package. Common icons are inlined, and other icons load from versioned same-origin sprites. Icons use semantic color and size tokens. The generated schema describes the capability without adding all 1,986 names to each model request.

Reproduce with `node scripts/generate-native-openui-spec.mjs --check`, `node scripts/generate-native-lucide-assets.mjs --check`, `node node_modules/tsx/dist/cli.mjs --test backend/src/ai/nativeOpenUi.test.ts` and `node scripts/verify-native-openui-browser.mjs <output-dir>`. These checks use no provider credential.
