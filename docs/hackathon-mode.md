# Hackathon mode

Status: **Implemented runtime**; organizer submission is an **external action**.

`hackathonRuntime.ts` compiles current official rules, deadlines, judging criteria, sponsor tracks, deliverables and prohibited actions. It scores product candidates by feasibility, validation and integration depth, builds a timeboxed plan, and runs a clean-reset golden demo twice to prove repeatability. It does not optimize for sponsor count alone.
