# Xroga UI/UX Step 1 Copy and Interaction Style

Xroga-owned copy is calm, direct, specific, and truthful. It uses sentence case and ordinary punctuation.

- Name the action: `Deploy`, `Publish`, `Send`, or `Delete records`, not `Proceed`.
- Name the blocker: `Reconnect GitHub to continue`, not `Something went wrong`.
- Preserve partial success. A failed publication does not erase a saved, verified project.
- Report only checks, files, sources, deployments, and external actions supported by evidence.
- Show structured activity, not private model reasoning or hidden scratchpads.
- Copy controls use the Lucide Copy icon, change briefly to Check + `Copied`, then restore without a global toast.
- Important live announcements are limited to task start, approval required, task completion, and task failure. Token and progress events are not individually announced.
