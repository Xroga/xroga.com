# Product experience audit

The final branch preserves the existing Xroga product while removing unsupported public claims and disconnected activity. The authenticated shell now uses the canonical navigation: New Terminal, Workspace, Dashboard, Repositories, Integrations, Publish, Operations, Growth, Plan & Usage, and Settings.

Verified changes include public-route availability during authentication configuration outages, protected-route fail-closed behavior, one canonical $19 plan, real usage pacing, real task and run events, four visual themes, accent/font/density/accessibility preferences, private-route search exclusion, and safe release evidence.

The primary chat bar has one icon-only voice control backed by browser speech recognition. It records only after a user click, never uploads audio or submits a prompt automatically, and exposes recording, processing, denied, and unavailable states.

No major brand redesign or static operations dashboard was added. Unsupported integrations remain labelled unavailable or external setup required.
