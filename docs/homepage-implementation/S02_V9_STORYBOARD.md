# S02 V9 storyboard: "Xroga in action"

One section, one physical computer, two ways in. Everything the visitor needs is inside one viewport at 1440×900.

## The set
A machined titanium display (bezel, soft rim light, contact shadow on a graphite floor). On the screen: a dark
Xroga desktop. The wallpaper is a deep cobalt-to-violet glass refraction taken from the orb's own colours, so the
screen reads as *a computer* (a MAUS lesson) without competing with the work. App windows float on it with real
depth (a Cursor lesson). At the bottom of the screen a glass **dock** holds the choices: four mission apps in
Browser Automation, the six AI Employees in AI Employees. Choosing never needs a scroll: the selector *is* the
computer's dock.

Above the display: eyebrow, one headline, one line, and the two-mode switch on the same row.

## Browser Automation (Xroga's blue pointer does one job in one real-looking app)
Each mission is 3 to 5 causal beats: request chip docks on the window, pointer travels to a real control,
hover, press, the app changes, a finding is pinned where it happened, a result window slides in beside the
browser. Sensitive steps stop at a visible approval. ~9-11 s, then it holds.

| Frame | Find a website bug | Prepare a Google Ad | Publish a Chrome extension | Prepare an article |
|---|---|---|---|---|
| 1 | Pricing page, pointer picks Pro | Ads editor, landing page checked | Release console, manifest open | CMS editor, article blocks |
| 2 | Checkout, coupon typed, total drops | Objective "Bookings", radius grows on map | Permissions narrowed (diff) | Image alt text, slug, meta |
| 3 | Upgrade loops back, error pinned | Headline typed, live ad preview | Smoke test in a mini browser | Phone preview: table overflows |
| 4 | DevTools: 422 on /checkout pinned | Budget set, Publish → approval | Listing assets + checklist | Table stacked, phone passes |
| 5 | Result: Upgrade blocked after coupon | Result: Draft ready, no money spent | Result: Release prepared, submit waits | Result: Article checked, publish waits |

## AI Employees (six glass-X colleagues, each with its own computer)
**Entrance (< 2 s):** the parent orb glows in the middle of the wallpaper; six companions rise from it on short
arcs (100 ms stagger), ties settle, they hold as a team on small light pedestals with names. Then the Software
Builder glides into its workspace and the other five shrink into the dock. The intro never replays by itself;
"Team" in the dock brings the lineup back.

**Companions:** the authentic glass X orb (cut from the founder's original), a role-coloured rim light and a
crafted miniature tie under the lower rim (six tie styles: slim, striped, bow, knit square-end, dotted, classic
with a titanium clip). Each has its own idle signature (nod, sway, tilt, settle, breathe) of 2-3 px.

| Employee | Computer | Beats → outcome |
|---|---|---|
| Software Builder (cobalt) | IDE + terminal | open file → bad line → diff → 18 tests pass → Patch ready for review |
| Growth Strategist (amber) | Prospect board + pipeline | Research brief arrives → shortlist → 3 pitch angles → pipeline; outreach waits for you |
| Research Analyst (violet) | Evidence canvas + matrix | sources → evidence → scored matrix → recommendation with uncertainty → hands brief to Growth |
| Creative Producer (rose) | Storyboard + format previews | frames → web / square / story versions → review notes → Assets ready, not posted |
| Data Specialist (teal) | Spreadsheet | duplicates grouped → bad emails fixed → before/after → 2 rows held → Records reconciled |
| Operations Manager (gold) | Inbox + calendar + CRM | request → calendar conflict → new slot → CRM updated → follow-up waits for you |

The companion floats at the corner of its own window and drives a cursor in its colour, so it is always clear
*who* is working. Each workspace scrolls on its own (only when the visitor scrolls inside it).

## Rules carried from the references
- Identity before product (MAUS 0-3 s), one big friendly character moment (Grok 16-19 s), every bot has a
  computer (MAUS 15-27 s), layered believable windows (Cursor 1 0-13 s), human signs in / approves (Grok 11-14 s,
  Cursor 2 14-17 s). Grammar only: no copied characters, UI or copy.
- No plan/phase labels, no progress bars, no pause/replay chrome. One small "Watch again" after a scene settles.
- One disclosure: "Illustrative experience · sample data".
