# SEO KPI specification

## Primary outcomes

- Non-brand organic clicks and impressions.
- Organic signup conversions.
- Qualified organic landing conversion rate.

## Leading indicators

- Non-brand queries receiving impressions.
- Queries in positions 1–3, 4–10, and 11–20.
- Priority pages receiving impressions.
- Indexed canonical priority URLs.
- Referring domains and evidence-asset mentions.

## Quality indicators

- Crawl/index errors, broken links, redirect chains, duplicate metadata, and malformed structured data.
- Core Web Vitals by page type using field data when available.
- Organic conversion quality and support burden.

Publishing volume is not a success KPI. Baselines and targets require an authorised Search Console/analytics export; otherwise report **NEEDS SEARCH CONSOLE**.
