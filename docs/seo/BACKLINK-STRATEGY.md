## Priority actions

1. Complete the official GitHub organization profile and ensure its website, name, logo, and description match `xroga.com`.
2. Keep X profile identity consistent; add no profile to `sameAs` until ownership is verified in repository configuration.
3. Prepare a Product Hunt draft only when anonymous users can evaluate a live product flow. Do not request coordinated/artificial votes.
4. Publish one useful open-source verification fixture set or benchmark harness with a stable methodology.
5. Pitch resulting evidence selectively to relevant developer editors. One tailored pitch is preferable to bulk outreach.

## Linkable assets

- AI coding-agent verification benchmark: public fixtures, acceptance criteria, raw outputs, versioned runners, limitations.
- Repository patch-safety corpus: examples of focused changes that preserve unrelated work.
- Deployment evidence checklist: an open checklist/tool that separates build success, provider acceptance, reachability, and release identity.
- State of AI coding-agent verification report: only after a reproducible multi-tool dataset exists.

Do not build a statistics page, comparison directory, or “best tools” list until XROGA has original evidence and a maintenance owner.
