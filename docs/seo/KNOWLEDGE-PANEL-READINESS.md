# XROGA AI Knowledge Panel readiness

## Implemented technically

- Canonical domain and organization URL: `https://xroga.com/`.
- Stable IDs: `#organization`, `#website`, `#software`, `#founder`, and `#logo`.
- Canonical organization name `XROGA AI`, alternate name `XROGA`, factual product description, official logo, contact point, founder relation, and repository-verified social profiles.
- WebSite entity publishes the preferred site name and references the organization.
- WebApplication and WebPage entities reference the same organization and website.
- About page has crawlable product, founder, contact, legal, and official-profile information.
- Official favicon assets, manifest, Open Graph image, canonical metadata, and sitemap/robots discovery.

## External corroboration required

Structured data helps systems reconcile entities; it does not guarantee a Knowledge Panel or site-name treatment. The owner should keep truthful, consistent facts on the official GitHub organization and official X account. Additional profiles should be added only after ownership is verified and their name, canonical URL, description, logo, and founder facts agree with the website.

Useful corroboration can come from legitimate product profiles, real integration partners, original open-source work, and independent editorial coverage earned because there is news or research to cover. Do not create or commission a Wikipedia page, Wikidata claim, review, award, press story, biography, customer list, or partnership merely to manufacture entity evidence.

## Data intentionally omitted

No founding date, street address, registration number, tax ID, VAT ID, LEI, NAICS code, awards, customer count, offices, funding, or third-party reviews are published in schema because the audited repository did not establish verified values. Add any future fact in one maintained configuration source before adding it to visible copy and structured data.
