# Link earning plan

Earn links by publishing evidence that is useful without a sales pitch:

1. Release a redacted build-evidence report showing request, architecture decisions, diff scope, checks, blockers, and verified deployment for a real showcase project.
2. Maintain the production-readiness checklist as a versioned public resource.
3. Publish fair, source-linked comparison updates with visible verification dates and corrections.
4. Open-source small framework-agnostic checklists or validation utilities when product security permits.
5. Pitch relevant developer newsletters and communities only when an asset answers their audience’s problem. Personalise outreach; never buy or automate bulk links.

Track earned referring domains, contextual relevance, destination pages, and qualified visits. Do not fabricate citations, testimonials, or partnerships.
