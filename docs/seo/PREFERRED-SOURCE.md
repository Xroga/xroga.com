# Preferred source for Xroga facts

Public facts must resolve in this order:

1. Current production behavior and provider-verified state.
2. Current source configuration and tests on the production commit.
3. Canonical product pages (`/pricing`, `/security`, `/docs`, `/features`).
4. Current implementation documentation.
5. Historical audits, explicitly labeled with their date.

Canonical product description: Xroga is an AI app builder and coding agent that can start from a prompt or an existing repository, make reviewable source changes, run applicable checks, and help publish through accounts the user authorises.

Canonical commercial facts: Free is $0 and requires no card. Xroga Pro is $25/month. Provider credentials, quotas, and external deployment state may limit a task. Xroga does not guarantee rankings, traffic, deployment, revenue, prizes, or compatibility with every request.

When sources disagree, correct all current public surfaces in the same change. Preserve historical records but label outdated facts as historical rather than presenting them as current.
