# SEO baseline and decisions — 2026-07-30

Targeted repository audit found indexable legacy feature pages with contradictory positioning (image/video negatives, provider/model labels, XRG rewards, Netlify, and inflated integration language), a sitemap that promoted those pages, only two documentation routes, no distinct crypto-hackathon resource, and no repeatable production metadata crawl.

The implementation establishes one product description, redirects legacy feature URLs to six distinct canonical capability pages, rebuilds the sitemap, preserves private-route noindex, adds docs/research/community routes, provides JSON/CSV research data, and adds a weekly production audit. Search volume, ranking difficulty, traffic, backlinks, and indexing are not claimed because no verified external dataset establishes them.

Historical repository documents are not rewritten when doing so would corrupt audit evidence. Active public routes and discovery files use the current positioning.
