# Batch 4 golden acceptance matrix (A–V)

Branch `claude/batch4-engine`, PR #881. Development only. The production hold stays in place. **No scenario below is live-verified.** Real model, real Google sandbox, real browser
against a deployed preview, R2 and live provider results are DEFERRED BY FOUNDER and are never counted as PASS here.

Levels: **contract** = unit/contract test; **local-process** = real OS processes or a real local database; **provider** = a real provider; **staging** = a deployed environment.
Status: PASS (the scenario's logic is proven at the stated level, nothing it needs is missing at that level), PARTIAL (some of it proven at the stated level), NOT_RUN (no test run for it in this work),
BLOCKED/DEFERRED (needs infrastructure, a model or a provider that is not authorised).

"This session" means a test written or run in the Claude continuation of Batch 4. "Existing" means a test in the tree that this work did not rerun; it is named so it can be rerun, and is not claimed as new evidence.

## Defects found by this work

1. The ledger functions were callable by `anon` on Supabase because default privileges grant EXECUTE directly; `REVOKE FROM PUBLIC` does not remove it. Caught by the real-database privilege test and fixed in the migration.
2. A request queued behind launch capacity was ended after five minutes as "worker stopped" and could not be launched. Fixed with a bounded queue wait and an accurate `never_started` reason.
3. A saved revision was reported durable on the insert receipt alone. It is now read back.
4. A real local Docker runtime reported "tests failed" for work that never ran (Batch 3, fixed earlier).
6. Redaction of every run event missed seven credential shapes (Basic auth, the second pair of a cookie header, JWTs, AWS keys, Google API keys, PEM private keys, `*_KEY=value` lines). Found by canary tests and fixed by adding patterns.
7. A reconnecting client with a cursor older than the retained 1000 events received a silent jump. The route now reports `eventsTruncated`.
8. My own process-test harness could hang on a child that exited before its close listener attached. Fixed in the test.
